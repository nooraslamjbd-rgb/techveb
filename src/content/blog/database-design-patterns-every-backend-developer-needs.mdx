<h2>Designing for Production</h2><p>Good database design impacts performance and maintainability.</p><h2>Normalization</h2><p>Normalize to 3NF by default. Denormalize strategically for reads.</p><h2>Indexing</h2><p>Index columns in WHERE, JOIN, ORDER BY. Monitor slow query logs.</p><h2>Soft Deletes</h2><p>Use deleted_at timestamp instead of DELETE. Preserve for auditing.</p><h2>Audit Columns</h2><p>Include created_at, updated_at in every table. Trivial to implement.</p>
