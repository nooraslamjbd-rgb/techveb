  - question: "What is Docker multi-stage building?"
    answer: "Multi-stage building uses multiple FROM statements in a Dockerfile to separate build dependencies from runtime, drastically reducing image size."
  - question: "Why should you avoid running Docker containers as root?"
    answer: "Running as root increases security risks; if a container is compromised, attackers might gain elevated access to the host system."
  - question: "How do you optimize Docker image sizes?"
    answer: "Use minimal base images like Alpine, implement multi-stage builds, clean cache files, and exclude unneeded files with .dockerignore."
  - question: "What is the purpose of Docker Compose?"
    answer: "Docker Compose allows developers to define, configure, and run multi-container applications using a single YAML configuration file."
