faq:
  - question: "What is event-driven architecture (EDA)?"
    answer: "Event-driven architecture is a software design pattern where decoupled microservices asynchronously publish and consume state-change events."
  - question: "What is the difference between Apache Kafka and RabbitMQ?"
    answer: "Apache Kafka is built for high-throughput event streaming and log persistence, whereas RabbitMQ excels at complex message routing and queuing."
  - question: "What are common patterns in event-driven architecture?"
    answer: "Key architectural patterns include Event Sourcing for auditability, CQRS for read/write separation, and Saga for managing distributed transactions."
  - question: "How do you handle consistency in event-driven systems?"
    answer: "Event-driven systems rely on eventual consistency, managing state synchronization across services using idempotent event consumers and transaction sagas."
