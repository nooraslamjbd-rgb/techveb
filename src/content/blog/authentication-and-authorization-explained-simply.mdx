faq:
  - question: "What is the difference between authentication and authorization?"
    answer: "Authentication verifies who a user is (identity), while authorization determines what resources or actions that authenticated user can access."
  - question: "What is the difference between JWT and session authentication?"
    answer: "JWTs store identity data statelessly on the client side, whereas session authentication maintains user state on the server."
  - question: "Why should you use WebAuthn and passwordless login?"
    answer: "WebAuthn provides secure, phishing-resistant authentication using biometrics or hardware keys instead of vulnerable passwords."
  - question: "When should you use OAuth 2.0 with PKCE?"
    answer: "Use OAuth 2.0 with PKCE (Proof Key for Code Exchange) for single-page applications and mobile apps to prevent authorization code interception."
keyTakeaways:
  - "Authentication verifies identity, while authorization controls user access permissions."

  - "JWTs enable stateless authentication, whereas server-side sessions provide centralized access control."
  - "OAuth 2.0 handles access delegation using flows like PKCE for SPAs and client credentials."
  - "Never build custom auth systems; use established security libraries or dedicated identity providers."
