<h2>Code for Humans</h2><p>Clean code is readable, maintainable, self-documenting.</p><h2>Names</h2><p>Reveal intent. Searchable. No abbreviations. Functions describe what not how.</p><h2>Small Functions</h2><p>One thing done well. Under 20 lines. If you need a comment, split it.</p><h2>DRY Nuanced</h2><p>Mild duplication is better than premature abstraction.</p><h2>Boy Scout</h2><p>Leave code cleaner than you found it. Small improvements compound.</p>
