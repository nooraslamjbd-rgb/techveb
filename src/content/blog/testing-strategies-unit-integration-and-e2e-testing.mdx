<h2>The Testing Pyramid</h2><p>Many unit tests, fewer integration, minimal E2E.</p><h2>Unit Tests</h2><p>Test functions in isolation. Mock dependencies. Focus on edge cases.</p><h2>Integration</h2><p>Test how components work together. Use testcontainers for databases.</p><h2>E2E</h2><p>Test critical user journeys. Playwright or Cypress. Limit to high-value paths.</p><h2>TDD</h2><p>Write tests before code. Red-green-refactor produces cleaner code.</p>
