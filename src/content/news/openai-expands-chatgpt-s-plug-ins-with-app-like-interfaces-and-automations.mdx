OpenAI isn’t only coming after productivity software with ChatGPT’s new Pages, Slides, and Space features — the AI lab is now targeting any application that could work better when integrated with ChatGPT.

At the company’s DevDay presentation on Tuesday, the AI company said it is now allowing developers to build their own app-like experiences within ChatGPT using plug-in extensions.

OpenAI already supports [plug-ins](https://chatgpt.com/features/plugins/), which connect ChatGPT to everyday tools like Slack, SharePoint, Airtable, and Google Drive, but the new plug-in extensions will give apps a dedicated home in the ChatGPT sidebar.

Plus, developers will be able to build interactive panels that let users work with their tools while they’re chatting with ChatGPT. This experience can also include file viewers that support whatever file formats the developer’s product uses, the company notes.

In addition, OpenAI says it’s making it easier for developers to build plug-ins and streamline the discovery process for end users. Devs are getting a new Plugin Creator tool for building and can submit them to the plug-in directory via a redesigned flow that offers clearer feedback.

Meanwhile, the company says it has improved how plug-ins are ranked and recommended within its directory, as well as when they’re surfaced in conversations. When users choose a plug-in to work with, they can approve its access needs individually as well.

In addition, ChatGPT Sites, the lightweight websites users can build with ChatGPT, can host these plug-ins, too. For example, this would let someone share their apps with colleagues, who can use them with their own connected data and permissions.

OpenAI also said it’s adding support for the proposed [MCP Events specification,](https://modelcontextprotocol.io/community/working-groups/triggers-events) which would allow plug-ins to start automations based on events in a connected app. The company is also making automations easier to add and manage.
